# జతపరుచు (Connect the Dots)

An educational Telugu cultural matching game where players associate revered mythological characters, deities, and historical personalities with their symbolic divine weapons, vahanas (mounts), and iconic insignia.

## Features
- Interactive drag-and-connect Canvas matching interface.
- Rich cultural lore connecting characters like Sri Rama (Kodanda bow), Shiva (Trishula), and Saraswati (Veena).
- Offline-first progress tracking with automatic Firestore cloud sync via `games/common/progress.js`.
- Responsive level grid with sequential chapter unlocking.
