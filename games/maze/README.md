# చిక్కుముడి (Cultural Labyrinth / Maze)

A navigation and spatial logic puzzle guiding spiritual seekers and historical characters through sacred labyrinths inspired by traditional temple architecture and mythological journeys.

## Features
- Procedurally solvable labyrinth paths with sacred checkpoints.
- Keyboard, touch, and swipe control integration for mobile and desktop.
- Multi-tier levels scaling in complexity from easy 8x8 grids to complex 20x20 labyrinths.
- Synced completion times and milestones.
