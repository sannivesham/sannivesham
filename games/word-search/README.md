# పద శోధన (Word Search)

A Telugu language vocabulary and word discovery puzzle designed to enrich knowledge of classical literature, Telugu proverbs (సామెతలు), epic characters, and Sanskrit-derived cultural terms.

## Features
- Dynamic Telugu grapheme grid supporting compound conjunct characters (సంయుక్తాక్షరాలు and పొల్లులు).
- Directional word matching (horizontal, vertical, diagonal).
- Clue descriptions, word meanings, and pronunciation highlights.
- Cloud progress synchronization via `games/common/progress.js`.
