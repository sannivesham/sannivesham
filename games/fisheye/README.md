# మత్స్య యంత్రం (Matsya Yantra)

An archery and timing-based concentration game inspired by the legendary Draupadi Swayamvara episode in the Mahabharata, where Arjuna strikes the eye of a rotating fish by looking solely at its water reflection.

## Features
- Precise rotating target mechanics with dynamic speed variations.
- Reflection calibration challenging user hand-eye coordination and timing.
- Cloud progress tracking saving best times and accuracy scores.
- Cultural storytelling cards accompanying each level.
