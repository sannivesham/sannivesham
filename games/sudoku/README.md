# సుడోకు (Sudoku)

A logical number puzzle blending classical mathematical logic with Telugu and standard numerals across cultural themes.

## Features
- Multiple difficulty presets (Easy 4x4, Medium 6x6, Hard 9x9).
- Bilingual numerical modes: Standard Digits (`1-9`) and Telugu Numerals (`౧, ౨, ౩, ౪, ౫, ౬, ౭, ౮, ౯`).
- Conflict detection, timer tracking, and persistent cloud completion records.
- Integrated hints and auto-verification.
